# 본부 브리핑 상세 리포트 작성 기준

상태: 2026.11.09. 사용자 채택 기준. PDF 첨부 방식으로 구현하며, 후보 추출과 본문 작성·검수를 구분함.

## 목적

기존 브리핑은 당일 동향을 빠르게 파악하는 용도로 유지함. 상세 리포트는 준법감시본부가 규제 변화, 감독상 유의점 및 업무 참고사항을 이해하는 데 추가 설명이 필요한 사안에 한하여 작성함. 개인 지식관리 체계와 연결하지 않음.

## 작성 대상의 판단

다음 세 조건을 모두 충족하는 사안을 대상으로 함.

1. 업무 관련성: 보험회사 준법감시, 내부통제, 금융소비자보호 또는 관련 부서에 대한 규제 안내·점검 업무와 구체적인 관련성이 있음.
2. 상세 설명의 실익: 변경 전후, 시행·경과조치, 판단 이유·적용 범위, 복수 자료의 관계 중 하나 이상을 설명해야 이해할 수 있으며, 메일의 짧은 요약만으로는 중요한 내용이 빠짐.
3. 근거 확보: 공식 원문 또는 해당 설명을 뒷받침할 공식 자료를 확보함. 보도자료만 확보한 경우 설명 범위를 그 자료에 한정하고, 규정 원문 미확인 사항은 확정 의무로 서술하지 않음.

HIGH 등급이나 조회 수만으로 작성하지 않음. 대상이 없으면 작성하지 않으며, 일일 발송 요청 시 핵심 사안 0~1건을 우선함. 밀접한 복수 자료는 하나로 묶고, 중대한 별도 사안이 있을 때만 추가함.

## 자료 유형별 작성 실익

| 유형 | 작성할 만한 경우 | 핵심 정리 내용 |
| --- | --- | --- |
| 법령·제도 변경 | 의무·절차·기한이 달라지거나 시행 시점·경과조치가 복잡한 경우 | 변경 전후, 적용 대상·시점, 업무 참고사항 |
| 판결·분쟁조정 | 보험·금융 업무의 판단에 참고할 새로운 판단 또는 적용 범위 설명이 필요한 경우 | 사실관계, 쟁점·판단 이유, 유사 업무 참고사항 및 적용 한계 |
| 제재·검사·감독 안내 | 구체적인 위반 유형·통제상 취약점·감독상 유의사항을 확인할 수 있는 경우 | 지적된 행위, 근거·판단, 점검 시 참고사항 |
| 연관 동향 종합 | 여러 공식 자료가 동일 쟁점을 다루며 함께 읽어야 변화가 드러나는 경우 | 공통 쟁점, 자료별 차이·진행 단계, 추가 확인사항 |

단순 행사·통계 발표, 기존 내용의 반복, 회사 업무와 연결 근거가 약한 사안은 메일 요약과 원문 링크로 충분함. 입법예고·발의안은 확정 제도와 구분하며, 중요한 변화가 예상되는 경우에만 진행 단계와 관찰할 사항을 설명함.

## 서술 원칙

- 기본 구성: 주요 내용·진행경과 → 핵심 쟁점·변경사항 → 업무에 참고할 사항 → 공식 출처·확인 범위.
- 마지막 항목은 준법감시본부가 규제 동향을 점검하거나 관련 부서에 안내할 때 참고할 내용으로 작성함.
- 회사 내부 사정이나 담당 부서의 검토 없이 사내 조치·담당자·기한을 확정하거나 실행을 약속하지 않음.
- 확인된 의무, 참고 가능한 점검 관점, 미확인 사항을 구별함. 업무 참고사항을 도출할 근거가 없으면 억지로 추가하지 않음.
- 기존 리포트 이후에는 실질적인 변경이 있을 때 갱신하고 변경 내용을 표시함. 같은 내용의 재발표만으로 새 리포트를 만들지 않음.

## 보험업 관련 입법의 별도 기준

- 보험업법·시행령·감독규정은 영업·모집·상품·건전성·내부통제 등에 실질적인 영향을 주는 변경이면 우선 작성함.
- 금융소비자보호법 등 관련 법령은 보험회사에 적용되는 의무·책임·절차의 변화가 있을 때 작성함. 그 밖의 법령은 보험업에 미치는 구체적인 영향을 확인하여 선별함.
- 입법 취지·현재 단계 → 현행 대비 주요 변경사항 → 보험업 관련 영향 → 업무에 참고할 사항 순으로 작성함.
- 발의·입법예고·심사 단계는 미확정임을 표시하고 확정되는 경우의 예상 영향으로 서술함. 국회 가결과 공포·시행을 구분함.
- 같은 법안의 위원회 대안·수정안 또는 통과 등 실질적인 내용·단계 변화가 있을 때 갱신함. 유사 법안은 함께 비교할 수 있음.

## 수동 발송과의 연결

폐쇄망 이용으로 상세 리포트의 외부 링크 배포는 채택하지 않음. 일일 발송 요청 시 후보를 확인하고 필요한 리포트를 작성·검수한 뒤 PDF를 메일에 첨부함. 메일 본문에는 첨부파일명과 안내를 표시함. 공식 출처 주소는 PDF 안에 근거 식별용으로 남기되 열람을 전제로 설명을 생략하지 않음.

새 API나 서버 없이 원문과 작성 JSON을 바탕으로 PDF를 생성함. 프로그램은 후보와 선정 확인항목을 제안하며, 키워드만으로 최종 선정·법률적 평가를 확정하거나 리포트를 자동 작성하지 않음. 해당 요청을 처리하는 작업자가 근거를 확인하고 본문을 작성한 후 ready 상태로 설정함. 이는 별도의 사용자 승인 절차를 요구하는 의미가 아님.
